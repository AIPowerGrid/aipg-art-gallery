# AIPG Art Gallery

Free AI image generation powered by a decentralized network of community-run GPU workers.

## How It Works

```
You describe an image
        ↓
Distributed workers compete to generate it
        ↓
Workers earn AIPG tokens for their GPU time
```

The AI Power Grid is a decentralized compute network where anyone can contribute GPU power and earn AIPG cryptocurrency. This gallery is the creative frontend: browsing is public, generation uses a linked Google or wallet Grid account, and every image is generated by real GPUs owned by real people around the world.

## Stack

| Layer    | Tech                                                                |
| -------- | ------------------------------------------------------------------- |
| Frontend | Next.js 14, Tailwind, RainbowKit                                    |
| Backend  | Go API server                                                       |
| Auth     | Google and SIWE (Sign-In with Ethereum) on Base                     |
| Storage  | PostgreSQL + Cloudflare R2                                          |
| AI       | Distributed workers running Flux, WAN, and other open-source models |

## Quick Start

```bash
# Install
npm install

# Run frontend (port 3000)
npm run dev

# Run backend (port 4000) — must run from server/ (Go module lives there)
cd server && go run ./cmd/api
# or: npm run dev:server
```

Copy `.env.example` to `.env` and fill in your credentials.

When `POSTGRES_ENABLED=true`, the Go service applies the embedded, checksummed
migrations in `server/internal/gallery/migrations/` before serving traffic.
Those migrations are the database source of truth; `supabase/schema.sql` is
retained only for the retired direct-Supabase prototype.

**Do not** run `go mod init` at the repo root — the Go module is `server/go.mod`.
Running `go run ./server/cmd/api` from the repo root will fail; always `cd server` first.
The API discovers the canonical repo-root `config/styles.json` whether it is
started from the repo root or from `server/`; `STYLES_CONFIG_PATH` is only an override.
